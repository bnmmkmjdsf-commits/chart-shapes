# PEREGRAPH

決算の良かった銘柄（業績タブ）を、日本株・米国株それぞれ週足のチャートで並べたページ。
持っている銘柄の「持ち株」タブ、気になる銘柄の「★ 注目」タブもあり（どちらも `watch.json` に書いた銘柄が、どの端末にも出る）。
無料のデータ（Yahoo Finance と JPX）だけで作り、GitHub Actions が平日に更新して GitHub Pages で公開している。

https://bnmmkmjdsf-commits.github.io/chart-shapes/

## チャート

カードのチャート（業績・持ち株・注目）は週足だけ。13週線・26週線・52週線を描く。日足などほかの足は、銘柄を押した先の株探で見る。銘柄ごとのファイルには、ポートフォリオ用の月足も入れている。
本数は `screener/gallery.py` の `FRAMES`。

## 抜けの札

「持ち株」と「★ 注目」のカードには、週足で13週線が26週線を抜けたばかり（1週前まで）のときに「週足 上抜け」「週足 下抜け（1週前）」のような札が出る
（`screener/gallery_template.html` の `FRESH`、判定は `screener/cross.py`）。
株価は広く取る（日本株は東証の全銘柄、米国株は時価総額3億ドル以上）。

## 持ち株と注目（watch.json）

日経平均（コード `N225`）とナスダック100（`NDX`）は、注目に最初から入れてある。指数は `screener/gallery.py` の `INDEXES` に書くと、同じようにチャートと札が出る。

「持ち株」と「★ 注目」に出す銘柄は、リポジトリの `watch.json` に書く（共通の一覧）。ページがそれを読むので、どの端末で開いても同じ銘柄が出る。
変えるときは Claude に「○○を注目に入れて」「○○を外して」と伝えて書き換えてもらう。main に入ると、1分ほどで見た目だけ作り直される。

```json
{
  "hold": {"jp": ["7011", "268A"], "us": []},
  "fav": {"jp": [{"code": "6971", "price": 2977, "from": "11/15"}], "us": []}
}
```

- 持ち株はコードだけ。注目は、☆を付けた日の株価（price）と日付（from）も持ち、そこから今までの値動きを出す
- どちらのカードも、週足のチャートと、抜けたばかりのときの札が出る。持ち株は、抜けたばかりの銘柄が先に並ぶ
- リポジトリは公開なので、ここに書いたコードは誰でも見られる（株数や買値は書かない）

ページの☆・「足す」・× は、その端末だけに残る（ブラウザの localStorage。足した銘柄は `favorites-v1`・`holdings-v1`、共通の一覧から外した銘柄は `hidden-v1`）。

## 銘柄ごとのファイル

持ち株と注目のチャートは、ページに埋め込まず、銘柄ごとのファイル（`s/市場/コード.json`）からページが読む。
全銘柄ぶんを埋め込むと重いため。全銘柄ぶんのファイルを作るのは、ページで☆を押した・足しただけの銘柄（その端末だけ）にもチャートを出すため。
ファイルを軽くするため、始値・高値・安値は終値からのずれ（千分率）で持ち、移動平均はページ側で計算する。
片方の市場だけ取り直すときは、もう片方の市場のファイルを公開中のページから引き継ぐ（`update.yml` が先に gh-pages を取ってくる）。

## 業績タブ

株探の決算速報（https://kabutan.jp/news/）の見出しから、直近45日の日本株を「好決算」と「改善」の2つに分けて並べる。

- 点数: 「最高益」3点、「上方修正」2点、「増配・増額」1点、「7-9月期も34％増益」「10-12月期も2倍増益」のような直近の3か月の伸び1点（どの3か月でも）。3点以上を載せる。減益・下方修正・赤字の見出しは外す
- 好決算: 決算の発表から株価が5%以上上がり、かつ相場全体（日経平均）より5%以上大きく上がった銘柄だけ。そのあとに悪い決算（減益・下方修正・赤字・減配など）が出た銘柄は外す（新しい方を信じる）。同じ銘柄は、好決算と改善の両方には出さない（好決算を優先）
- 株探は GitHub Actions からのアクセスを断る（HTTP 405）ので、株探を読むのは Claude のセッション（平日 16:1x の予定の作業）か手元のパソコン。
  `python -m screener.earnings` で前回の続きだけ読み（1秒おき）、結果の `earnings.json` を main に push する。初回は45日分で数分、2回目からは数秒〜1分
- 日本株の更新（夕方16:30）が `earnings.json` を読み、その日の株価で、決算の発表からの動きを出す。`earnings.json` が無い・読めないときは業績タブが空になる（ほかは止まらない）
- 株探の非公式な読み取りなので、ページの作りが変わると読めなくなる
- 改善: 赤字縮小・黒字浮上・黒字転換・増益・上方修正・増配など良くなった決算のうち、好決算（3点以上）に入らなかったもので、発表から株価が5%以上上がり、かつ相場全体（日経平均）より5%以上大きく上がった銘柄。「配当を見送り」や「7-9月期は減益」（直近の3か月は減益）のように、見出しのどこかに悪い話が付いたものは外す。同じ銘柄に、それより新しい好決算や悪い決算（減益・下方修正・赤字など）が出ていれば外す。`earnings.json` の `improve` を使う（`improve` が無い古い `earnings.json` なら、自動で1回だけ全部読み直す）
- 条件は `screener/earnings.py` の先頭にある
- 並び順は、日米・好決算・改善とも、1日の売買代金の大きい順（大型株・よく売買される銘柄が上に来る）
- 一覧に入って3日のあいだは、カードに「新」が付く。どのカードにも「11/20から」のように入った日が出る（前回の公開ページの一覧と比べて決める。`since`）
- 日米とも、1日の売買代金（終値 × 出来高。直近20日の中央値）が日本株は30億円以上、米国株は2億ドル以上の銘柄だけ載せる（`screener/gallery.py` の `MIN_TURNOVER`）。売りたいときにすぐ売れる銘柄だけにするため

米国株は、Yahoo Finance の決算の予定表（1株利益の予想と実績）から、直近45日に決算を出した時価総額3億ドル以上の銘柄を拾う（業績タブの「日本株／米国株」で切り替え）。

- 好決算: 黒字で、1株利益が予想を10%以上上回り、発表から株価が5%以上上がり、かつ相場全体（ナスダック100）より5%以上大きく上がった銘柄
- 改善: 赤字だが、1株利益が予想を10%以上上回り（赤字縮小にあたる）、発表から株価が5%以上上がり、かつ相場全体（ナスダック100）より5%以上大きく上がった銘柄
- 予想が0.10ドルより小さい銘柄は外す（少しの差でも何百%にもなるため）
- 米国株の更新（朝7:00）のときに GitHub Actions が読む。読めないときは4回まで読み直し、それでも駄目なら公開中のページの分を残す（ほかは止まらない）

## 売買代金タブ

日本株・米国株それぞれ、取引が終わった直近の1日の売買代金（終値 × 出来高）の大きい順に50銘柄（`screener/gallery.py` の `RANK_COUNT`。SBI証券のランキングと同じ50位まで）。
カードには順位・売買代金・前の日からの値動きを出す。指数は入れない。株価を取り直すとき（日本株は夕方、米国株は朝）に作る。

## ポートフォリオ（portfolio.html）

ページ上の「ポートフォリオ →」から開く。日米株で組むポートフォリオと、その過去の成績（`screener/portfolio.py`、見た目は `screener/portfolio_template.html`）。

- 組み方: 市場ごとに、半分は指数（日経平均・ナスダック100）、半分は上昇率TOP20（12か月前から1か月前までの上がり方の上位20銘柄）に同じ金額ずつ。日米は GPIF の国内株・外国株と同じく半々。毎月の終わりに組み直す
- 指数を入れない「上昇率TOP20だけ」も、日米半々と日本25%・米国75%で出す。ページを開くと日本25%・米国75%（TOP20 米国多め）が出る（`screener/portfolio.py` の `MIXES`）。今の銘柄の表には上昇率も出し、上昇率の高い順に並べる
- 売買代金が足りる銘柄（日本株5億円・米国株2000万ドル以上。`screener/gallery.py` の `PORTFOLIO_MIN_TURNOVER`）だけ使う。ページを作るときに `s/市場/_liquid.json` に書き出す
- 数十通りの組み方（銘柄数・値動きの小さい銘柄を多めにする・指数が下向きなら現金で待つ・毎月その時点の一番に乗り換える など）を試し、前半・後半のどちらでも指数に勝ち、下げも大きくならなかった形にした
- 銘柄ごとの月足ファイルから作るので株価は取り直さない。株価の更新のたびに作り直す。作れなくてもほかのページは止まらない
- 手元で: `python -m screener.portfolio --site site`
- 今も上場している銘柄だけで試すので、過去の成績は実際より良く出る。配当・為替は入れていない

## チャート当てクイズ（quiz.html）と次のモデルナ探し（shape.html）

どちらもページ上のリンクから開く（`screener/play.py`、見た目は `screener/quiz_template.html`・`screener/shape_template.html`）。株価は取り直さず、銘柄ごとの月足ファイルから作る。

- チャート当てクイズ: 売買代金が足りる銘柄（`_liquid.json`）から、銘柄と時期をでたらめに選び、名前を隠した月足（最大48か月）を出す。その後の1年で上がったか下がったかを当てる。ページが銘柄ごとのファイルを読んで問題を作るので、毎回ちがう問題になる。成績はその端末だけに残る（localStorage の `quiz-score-v1`）
- 次のモデルナ探し: 過去に1年で3倍以上になった銘柄の「上がる前の12か月の形」を手本にし、今の12か月の形が一番似ている銘柄を20ずつ並べる（形は株価の対数を平均0・ばらつき1にそろえて比べる）。
  当たりやすさも、過去の各月で「その月までに分かった手本」だけを使って選んだとして試し、2倍以上・半分以下になった割合を全体と比べてページに出す。
  米国株では2倍以上になる割合が全体の約2倍だが、半分以下になる割合も高い。日本株では全体とほぼ同じ

## 更新のしかた

`.github/workflows/update.yml` が動かす。

- 平日の朝7:00（日本時間、米国市場の終値のあと）に米国株、夕方16:30（東証の終値のあと）に日本株を取り直す。
  動いていない方の市場は、公開中のページのデータをそのまま使う
- 手動で動かすとき: `gh workflow run update.yml --ref main`（日米とも取り直す）
- 見た目や文言だけ変えたとき: `gh workflow run update.yml --ref main -f reuse_data=true`（株価を取り直さず、20秒ほどで終わる）
- main 以外のブランチで動かすと公開はせず、作ったページを Actions の成果物（`page`）に残す

## 手元で動かす

Windows のパス長制限を避けるため、仮想環境はプロジェクトの外（短いパス）に作る。

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m venv "$env:USERPROFILE\.venvs\us-screener"
& "$env:USERPROFILE\.venvs\us-screener\Scripts\python.exe" -m pip install -r requirements.txt
& "$env:USERPROFILE\.venvs\us-screener\Scripts\python.exe" -m screener.gallery   # → site/index.html
```

## 構成

| ファイル | 役割 |
|---|---|
| `screener/prices.py` | Yahoo のスクリーナー API から株価・時価総額（米国・日本）、yfinance で日足（週足はここから作る。決算の発表からの値動き・売買代金にも使う）と月足（ポートフォリオ用） |
| `screener/jpx.py` | JPX の東証上場銘柄一覧から、日本語の銘柄名・33業種 |
| `screener/cross.py` | 移動平均と、短期線が中期線を抜けたかの判定 |
| `screener/earnings.py`, `earnings.json` | 株探の決算速報（日本株）と Yahoo Finance の決算の予定表（米国株）から、業績の良い銘柄と悪い銘柄を拾う |
| `screener/gallery.py`, `screener/gallery_template.html` | ページの書き出しと、ページの見た目 |
| `screener/watch.py`, `watch.json` | 持ち株と注目の銘柄（どの端末にも出す共通の一覧） |
| `screener/portfolio.py`, `screener/portfolio_template.html` | ポートフォリオのページ |
| `screener/play.py`, `screener/quiz_template.html`, `screener/shape_template.html` | チャート当てクイズと次のモデルナ探し |
| `screener/published.py`, `screener/retemplate.py` | 公開中のページのデータを取り出す・それを使ってページだけ作り直す |

## 制約

- Yahoo は非公式 API なので、仕様変更や回数制限で止まることがある
- 祝日は見ていないので、休場日は前の営業日の足のままになる
- 以前あった日本株・米国株の「移動平均の抜け」の一覧（1時間足・日足・週足・月足、上抜け・下抜け）と取引時間中の1時間足の更新、持ち株の状態（崩れ・注意・横ばい など）、「下ひげ × 出来高増」の一覧、「二択」タブ、「崩れ」の一覧、過去の成績、ページ下の注意書きは、使わなくなったので消した。Git の履歴には残っている
- 以前あった米国株の財務スクリーナー（SEC EDGAR）とチャート形状検索（Streamlit）は、使わなくなったので消した。Git の履歴には残っている
