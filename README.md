# PEREGRAPH

1時間足・日足・週足・月足で、短期の移動平均線が中期線を上に抜けた・下に抜けた銘柄を、日本株・米国株それぞれチャートで並べたページ。
持っている銘柄の「持ち株」タブ、気になる銘柄の「★ 注目」タブもあり（どちらも `watch.json` に持ち、ページで足し外しするとどの端末にも出る）、どちらも同じチャートと、抜けたばかりのときの札が出る。
無料のデータ（Yahoo Finance と JPX）だけで作り、GitHub Actions が平日に更新して GitHub Pages で公開している。

https://bnmmkmjdsf-commits.github.io/chart-shapes/

## 条件

取引が終わった直近の足で、短期線が中期線を抜けた銘柄を、「上抜け」「下抜け」に分けて売買代金の大きい順に並べる。
前の足では短期線が中期線以下で、その足で上に出たら上抜け。逆が下抜け。

| 足 | 短期線 | 中期線 | 長期線（描くだけ） |
|---|---|---|---|
| 1時間足 | 25本 | 75本 | 200本 |
| 日足 | 5日 | 25日 | 75日 |
| 週足 | 13週 | 26週 | 52週 |
| 月足 | 12か月 | 24か月 | 60か月 |

一覧に載せるのは、日本株・米国株それぞれ、1日の売買代金（終値 × 出来高。直近20日の中央値）の大きい順に200銘柄。
全銘柄を見るのをやめ、いつでも売り買いできる、資金の集まっている銘柄だけにしている。株価が日本株は100円未満、米国株は5ドル未満の銘柄は入れない。

本数としきい値は `screener/gallery.py` の先頭にある。判定は `screener/cross.py`。

## 抜けの札

「持ち株」と「★ 注目」のカードには、その銘柄が抜けたばかりのときに「日足 上抜け」「週足 下抜け（1週前）」のような札が出る。
出すのは、1時間足は6本前まで（ほぼ1日ぶん）、日足は2日前まで、週足は1週前まで、月足は直近の月だけ（`screener/gallery_template.html` の `FRESH`）。
売買代金の上位200に入らない銘柄でも札が出るよう、株価は一覧より広く取る（日本株は東証の全銘柄、米国株は時価総額3億ドル以上）。

## 持ち株と注目（watch.json）

日経平均（コード `N225`）とナスダック100（`NDX`）は、注目に最初から入れてある。指数は `screener/gallery.py` の `INDEXES` に書くと、同じようにチャートと札が出る（一覧の200銘柄には入らない）。

「持ち株」と「★ 注目」に出す銘柄は、リポジトリの `watch.json` に持つ。ページがそれを読むので、どの端末で開いても同じ銘柄が出る。

ふだんはページで足し外しする（☆、持ち株タブの「足す」と ×）。押すとページが GitHub の `watch.json` を直接書き換え、1分ほどでページが作り直されて、どの端末にも出る。
書き換えには合言葉（GitHub のトークン）が要る。端末ごとに初めて押したときに聞かれ、その端末のブラウザ（localStorage の `github-token-v1`）に残る。

合言葉の作り方（1回だけ。同じものをどの端末にも貼ってよい）:

1. GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
2. Repository access は「Only select repositories」で `chart-shapes` だけを選ぶ
3. Permissions の Contents を「Read and write」にする
4. 期限（Expiration）は長めにする。切れたら、ページが「もう一度入れてください」と出すので作り直す

```json
{
  "hold": {"jp": ["7011", "268A"], "us": []},
  "fav": {"jp": [{"code": "6971", "price": 2977, "from": "11/15"}], "us": []}
}
```

- 持ち株はコードだけ。注目は、☆を付けた日の株価（price）と日付（from）も持ち、そこから今までの値動きを出す
- どちらのカードも、一覧と同じチャート（1時間足・日足・週足・月足を切り替えられる）と、抜けたばかりのときの札が出る。持ち株は、抜けたばかりの銘柄が先に並ぶ
- `watch.json` を直接書き換えても、main に入れば見た目だけの作り直しで反映される
- 取引時間中の更新は、ここの銘柄の1時間足も取り直す（売買代金の上位200の外でも）
- リポジトリは公開なので、ここに書いたコードは誰でも見られる（株数や買値は書かない）
- 以前この端末だけに保存していた☆と持ち株（`favorites-v1`・`holdings-v1`）は、合言葉を入れたときに `watch.json` へ移す

## 銘柄ごとのファイル

持ち株と注目のチャートは、ページに埋め込まず、銘柄ごとのファイル（`s/市場/コード.json`）からページが読む。
全銘柄ぶんを埋め込むと重いため。全銘柄ぶんのファイルを作るのは、ページで☆を押した・足しただけの銘柄（その端末だけ）にもチャートを出すため。
ファイルを軽くするため、始値・高値・安値は終値からのずれ（千分率）で持ち、移動平均はページ側で計算する。
片方の市場だけ取り直すときは、もう片方の市場のファイルを公開中のページから引き継ぐ（`update.yml` が先に gh-pages を取ってくる）。

## 業績タブ

株探の決算速報（https://kabutan.jp/news/）の見出しから、直近45日で業績の強い日本株を拾い、チャートの形で分けて並べる。

- 点数: 「最高益」3点、「上方修正」2点、「増配・増額」1点、「7-9月期も増益」のような直近の四半期の伸び1点。3点以上を載せる。減益・下方修正・赤字の見出しは外す
- 並び: 点数の高い順。同じ点数なら、増益率か上方修正の幅の大きい順
- 形: 日足は直近60日、週足は直近30週を3つに区切り、区切りごとの高値・安値を比べる。両方切り上がりなら上昇、両方切り下がりなら下降、ぶれが日足6%・週足10%以内ならレンジ、それ以外は転換中
- レンジ上抜け: 直近の足を除いた期間がレンジで、直近の終値がその期間の高値を超えた銘柄。持ち株・注目のカードにも「レンジ上抜け（好業績）」の札が出る
- 株探は GitHub Actions からのアクセスを断る（HTTP 405）ので、株探を読むのは Claude のセッション（平日 16:1x の予定の作業）か手元のパソコン。
  `python -m screener.earnings` で前回の続きだけ読み（1秒おき）、結果の `earnings.json` を main に push する。初回は45日分で数分、2回目からは数秒〜1分
- 日本株の更新（夕方16:30）が `earnings.json` を読み、その日の株価で形を判定する。`earnings.json` が無い・読めないときは業績タブが空になる（ほかは止まらない）
- 株探の非公式な読み取りなので、ページの作りが変わると読めなくなる
- 業績悪・株価高: 減益・下方修正・赤字の決算（赤字縮小・黒字浮上・増益などの良くなった決算は除く）のあと、発表から5%以上株価が上がっている銘柄（上がった順）。ぶれが大きいので注意。`earnings.json` の `weak` を使う（`weak` が無い古い `earnings.json` なら、自動で1回だけ全部読み直す）
- 条件は `screener/earnings.py` の先頭にある

## 更新のしかた

`.github/workflows/update.yml` が動かす。

- 平日の朝7:00（日本時間、米国市場の終値のあと）に米国株、夕方16:30（東証の終値のあと）に日本株を取り直す。
  動いていない方の市場は、公開中のページのデータをそのまま使う
- 取引時間中は、1時間おきに1時間足だけを取り直す（日本株は10:25〜15:25、米国株は現地9:50〜15:50。株価が15〜20分遅れるので、足が終わってから少し待つ）。
  取り直すのは、一覧の銘柄（売買代金の上位200）と `watch.json` の銘柄だけ。日足・週足・月足は、取引が終わったあとの更新で変わる
- 1時間足だけを手動で取り直すとき: `gh workflow run update.yml --ref main -f hourly=true -f markets=jp`
- 手動で動かすとき: `gh workflow run update.yml --ref main`（日米とも取り直す）
- 見た目や文言だけ変えたとき: `gh workflow run update.yml --ref main -f reuse_data=true`（株価を取り直さず、20秒ほどで終わる）
- main 以外のブランチで動かすと公開はせず、作ったページを Actions の成果物（`page`）に残す

## 手元で動かす

Windows のパス長制限を避けるため、仮想環境はプロジェクトの外（短いパス）に作る。

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m venv "$env:USERPROFILE\.venvs\us-screener"
& "$env:USERPROFILE\.venvs\us-screener\Scripts\python.exe" -m pip install -r requirements.txt
& "$env:USERPROFILE\.venvs\us-screener\Scripts\python.exe" -m screener.gallery   # → site/index.html
```

## 構成

| ファイル | 役割 |
|---|---|
| `screener/prices.py` | Yahoo のスクリーナー API から株価・時価総額（米国・日本）、yfinance でローソク足（日足・月足）。週足は日足から作る |
| `screener/jpx.py` | JPX の東証上場銘柄一覧から、日本語の銘柄名・33業種 |
| `screener/cross.py` | 移動平均と、短期線が中期線を抜けたかの判定 |
| `screener/earnings.py`, `earnings.json` | 株探の決算速報から業績の強い銘柄を拾い（earnings.json に保存）、チャートの形（上昇・レンジ・転換中・下降）で分ける |
| `screener/gallery.py`, `screener/gallery_template.html` | ページの書き出しと、ページの見た目 |
| `screener/watch.py`, `watch.json` | 持ち株と注目の銘柄（どの端末にも出す共通の一覧） |
| `screener/published.py`, `screener/retemplate.py` | 公開中のページのデータを取り出す・それを使ってページだけ作り直す |

## 制約

- Yahoo は非公式 API なので、仕様変更や回数制限で止まることがある
- 祝日は見ていないので、休場日は前の営業日の足のままになる
- 以前あった持ち株の状態（崩れ・注意・横ばい など）、「下ひげ × 出来高増」の一覧、「二択」タブ、「崩れ」の一覧、過去の成績、ページ下の注意書きは、使わなくなったので消した。Git の履歴には残っている
- 以前あった米国株の財務スクリーナー（SEC EDGAR）とチャート形状検索（Streamlit）は、使わなくなったので消した。Git の履歴には残っている
